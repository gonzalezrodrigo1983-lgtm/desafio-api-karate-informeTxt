# Análisis de Reportes - APIs

## Reportes incluidos

## Interpretación esperada
La suite debe mostrar casos exitosos para endpoints positivos y fallas controladas para escenarios negativos. Los escenarios fallidos reales deben revisarse por código HTTP, contrato de respuesta o disponibilidad de la API pública.
